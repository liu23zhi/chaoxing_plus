Windows 启动参数生成器（离线运行，不执行命令，不保存输入）

版本 6.2.0

预设

生成器会导出当前宿主支持的普通运行、扫描、面板、答题、日志和诊断参数；内存执行、删除挂起、启动清理与自毁不会进入可运行命令。

客户端扫描

与扫描序号、首个候选互斥。

配置与数据

支持 JSON 对象或 @文件路径；独立命令行参数优先级更高。

此选项不控制 CXExam 自身的浏览器存储；启动错误或系统权限提示仍可能输出。

支持内联 JSON 对象和 @JSON 文件；内联 JSON 不支持配置删除、启动清理、自毁或非普通执行模式字段。

执行模式

默认根据此 HTML 的位置生成绝对路径；如果启动脚本单独移动，请在此修改。该路径只用于命令文本，不会写入 JSON。

答题

快捷键需包含一个基础按键；请仅在你有权操作的测试或练习环境使用。

启动清理与自毁

执行模式、启动清理和自毁当前不可执行；控件仅说明参数设计，不会进入输出。

未发布能力

内存执行、删除挂起、启动清理和自毁不会导出为可运行参数。“启动清理型”预设会显示阻止提示，避免静默降级。

校验结果
