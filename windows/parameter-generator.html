Windows 启动参数生成器（离线运行，不执行命令，不保存输入）

版本 6.2.0

预设

生成器会导出当前宿主支持的普通运行、扫描、面板、答题、日志和诊断参数；内存执行、删除挂起、启动清理与自毁不会进入可运行命令。

客户端扫描

与扫描序号、首个候选互斥。

Windows 上“GUI”与“交互选择”对应 --select-client，会弹出原生选择窗口（含手动浏览）；窗口不可用时回退终端提示。

配置与数据

支持 JSON 对象或 @文件路径；独立命令行参数优先级更高。

--no-retain-data 只清理本次运行创建的宿主数据；--delete-config 必须搭配 --config；两者都不影响 CXExam 自身的浏览器存储。启动错误或系统权限提示仍可能输出。

支持内联 JSON 对象和 @JSON 文件；内联 JSON 不能改变配置文件路径；未被独立命令行参数覆盖的字段会按宿主规则校验范围/枚举/类型，启动清理、自毁或非普通执行模式字段会被拒绝。

执行模式

默认根据此 HTML 的位置生成绝对路径；如果启动脚本单独移动，请在此修改。该路径只用于命令文本，不会写入 JSON。

日志与诊断

启动清理

当前宿主不可执行：这里只展示参数 schema 与范围校验，不会导出为可运行命令。

自毁

当前宿主不可执行：自毁快捷键与行为不会导出为可运行命令；答题快捷键不得与自毁快捷键相同。

未发布能力

内存执行、删除挂起、启动清理和自毁在当前宿主不可执行，不会导出为可运行参数。“启动清理型”预设会显示阻止提示，避免静默降级。

校验结果
