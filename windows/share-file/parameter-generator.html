超星学习助手

Windows 启动参数生成器（离线运行，不执行命令，不保存输入）

原生 EXE 版本 0.1.0

预设

默认生成原生单文件 EXE 的普通运行参数。内存执行表示宿主不写日志、配置、诊断或报告，客户端仍正常可见启动。启动清理型只展示设计，本页不导出通用启动清理、删除挂起或自毁参数；原生已有的固定静默场景与这些通用参数不同。

加载已有配置

读取本地配置并填回表单（顶层字段与 settings 共享设置）；不上传、不保存文件。

客户端扫描

与扫描序号、首个候选互斥。

Windows 上“GUI”与“交互选择”对应 --select-client，会弹出原生选择窗口（含手动浏览）；窗口不可用时回退终端提示。

配置与数据

原生 EXE 默认 .data，以 EXE 所在目录为工作目录；Node 兼容入口默认 windows\data，以项目根目录为工作目录。

支持 JSON 对象或 @文件路径；独立命令行参数优先级更高。

两种宿主都支持数据生命周期：--no-retain-data 只删除本次运行创建的日志/报告/诊断，--delete-config 只删除显式 --config 文件且不能与 --no-disk-write 同用。两者都不影响 CXExam 自身的浏览器存储。启动错误或系统权限提示仍可能输出。

支持内联 JSON 对象和 @JSON 文件；内联 JSON 不能改变配置文件路径；未被独立命令行参数覆盖的字段会按宿主规则校验范围/枚举/类型，executionMode 支持 normal、memory 与 delete-suspend，启动清理/自毁字段也会导出。

执行模式

默认使用原生客户端。Node 入口仅供历史兼容和排障；切换宿主不会自动降级功能。

需安装 Node.js 22+。默认根据此 HTML 的位置定位宿主；单独复制 HTML 后请填写实际的 windows\node-source\main.mjs 绝对路径，支持驱动器路径（含 C:/ 写法）或完整 UNC 路径。PowerShell 5.1/7 直接启动 Node，避免经批处理转交后破坏 JSON；路径只用于命令文本。

首次打开不预填路径：可直接粘贴完整路径，也可用“选择 EXE…”打开文件选择器。浏览器安全模型通常只返回文件名，若页面提示缺少完整路径，请把路径输入框补全为实际目录（例如 C:\Tools\chaoxing_plus.exe）。填好之前不会生成可运行命令。命令直接启动 EXE，无需 Node.js，并以 EXE 所在目录为工作目录；相对配置与数据路径均由此解析。原生诊断包含页面布局、页面 PNG、窗口 DPI、BMP/PNG 和宿主摘要。

原生能力：普通运行、宿主零写盘、扫描与选择、共享配置、面板、答题设置、日志与诊断已接入。input 方式已放弃开发，不再规划；cdp-pipe 仍是诊断通道，未完成常驻会话与重连；本页不为这两种方式生成启动命令。真实 CEF75 登录后及旧 Windows 环境仍需人工验收。

默认不提前申请；只在启动所选 CXExam.exe 确实需要管理员权限时请求 UAC。勾选后在扫描、显示 GUI 前申请；已是管理员时直接继续。帮助、自检、仅扫描和 attach 不申请。

只影响 Node 宿主控制台显示；原生 EXE 是 GUI 子系统，没有控制台。隐藏窗口不等于关闭日志、报告或系统权限提示。

CEF 注入兼容性

只连接本次启动客户端的本机 CDP 端点；不匹配时中止，避免误连其它浏览器。

沿用默认时不传 --inject-mode，由宿主与选择窗口判定方式；不保证采用端口方式，也不等同于显式 auto。

hybrid 是默认推荐策略；script 路径用于部分 CEF 页面 Runtime.evaluate 被拦截或执行上下文不稳定时的回退。

面板

内置浅色主题；未知名称由页面回退 pink，建议留空或从列表选择。

答题

快捷键需包含一个基础按键；请仅在你有权操作的测试或练习环境使用。

日志与诊断

原生默认位于数据目录的 chaoxing\diagnostics 子目录；修改数据目录时跟随调整，手动填写诊断路径后保留。

启动清理

只清理数据目录 chaoxing 下登记的扫描缓存、宿主日志与诊断产物；不会删除 CXExam、runtime、外部 --config 或用户报告。

自毁

默认弹 MessageBox 确认；--no-self-destruct-confirm 跳过确认。答题快捷键不得与自毁快捷键相同。

能力说明

本页支持导出普通运行、内存执行、删除挂起、启动清理与自毁参数；破坏性操作只在发布布局（EXE 同级 SHA256SUMS.txt）执行。原生固定静默场景不在本页导出范围内。
